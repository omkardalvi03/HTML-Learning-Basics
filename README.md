## 📂 Project Structure & Lessons

The cards on my index hub connect directly to these individual practice modules:

* **[registration-form](https://github.ioregistration-form/index.html)** — Full registration layout with text inputs, radio selections, checkboxes, textareas, and embedded iframe tools.
* **[table_internal_styling](https://github.iotable_internal_styling.html)** — Advanced baseball scoreboard matrix using IDs, classes, padding controls, custom margins, and thin border styling.
* **[css-implementation-methods](https://github.iocss-implementation-methods/index.html)** — A structural comparison master page demonstrating the simultaneous use of Inline, Internal, and External CSS files.

* **[image_events](https://github.ioimage_events.html)** — Interactive element event handler attributes tracking live mouse cursor hover-in, click, and hover-out actions.
* **[image_mapping](https://github.ioimage_mapping.html)** — Custom absolute CSS coordinate overlays dividing structural layout graphics into 50% box and 50% circle hover zones.
* **[popupboxes](https://github.iopopupboxes.html)** — Triggering programmatic native JavaScript popups including alert warnings, confirmation logs, and user data input prompts.
* **[text_formatting](https://github.iotext_formatting.html)** — Testing semantic baseline layouts utilizing typographic markers, edits tracking, markers, subscripts, and superscripts.
